# **App Name**: Granite Grid

## Core Features:

- Data Entry: Input granite length and width measurements for 100 rows using a streamlined form.
- Data Visualization: Display entered data in a grid format with clear column headers and row numbers.
- Basic Statistics: Calculate and display basic statistics (average, min, max) for length and width.
- Generate Summary: Employ generative AI to write a short text summary of the data entered in the grid.
- CSV Export: Allows exporting the data in CSV format for further analysis.

## Style Guidelines:

- Primary color: Deep slate blue (#34495E) to convey precision and reliability.
- Background color: Light gray (#F0F3F4) for a clean, neutral surface.
- Accent color: Muted teal (#77B5FE) for interactive elements and highlights, analogous to the primary hue.
- Body and headline font: 'Inter', a grotesque-style sans-serif, will be used for both headlines and body text.
- Simple, geometric icons to represent measurements and data functions.
- Clean, tabular layout for easy data entry and review, with clear visual separation between rows.
- Subtle transitions and highlighting on data entry to improve user experience.
